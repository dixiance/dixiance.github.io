ABOUT THE STUDIO

我们做的，是让光
停在故事该停的地方

精京影业成立于二〇〇八年，总部设在北京，并在上海与成都设有创作小组。 十六年间，我们从一间只有三台机器的剪辑室，成长为覆盖 开发、制片、拍摄、后期全链路的影像机构。

我们不以产量论英雄，而以每一部作品的完成度自省。片场里我们讲究秩序， 剪辑台前我们尊重直觉；面对客户，我们更愿意先听见问题，再谈方案。 影像工业的每一处细节，最终都会落在观众的那一次呼吸里。

如今，精京影业同时运营「精京青年影像计划」，每年支持六位新导演完成处女作短片， 并为其中优秀者提供长片开发的绿色通道。这是我们回馈行业的方式， 也是我们保持年轻的方法。

作者表达尊重导演语言，拒绝模板化叙事。
工业流程标准化制片管理，风险前置可控。
技术前沿虚拟制片、HDR 调色与沉浸声场。
长期主义与创作者建立五年以上的合作关系。

HOW WE WORK

从第一个念头，
到最后一个镜头

好作品不是灵感的结果，而是流程的产物。精京影业把项目拆成六个可控阶段，每个阶段都有明确的交付物与决策点，让创作者把精力留给创作本身。

概念与提案 PHASE 01

理解需求、明确受众与传播目标，输出概念方向与预算框架。我们会在动笔写脚本之前，先和客户确认「这支片子要解决什么问题」。

需求访谈创意方向预算测算

剧本与分镜 PHASE 02

完成文学剧本、分镜脚本与视觉参考，组织内部围读与客户评审。分镜精确到机位与时间码，让执行阶段的偏差降到最低。

文学剧本分镜绘制视觉参考

筹备与选角 PHASE 03

组建制片班子，完成场勘、器材、美术、服化道与演员试镜。所有拍摄计划以甘特图形式同步给项目各方，每日可查进度。

场勘选角制片排期

拍摄执行 PHASE 04

按通告单推进拍摄，DIT 现场数据双备份，每日收工前完成素材核对与粗剪素材整理，确保第二天开机无隐患。

现场制片DIT 管理日审素材

后期制作 PHASE 05

粗剪、精剪、调色、视效、混音与字幕包装，按标准版本管理，支持多版本交付（院线、流媒体、社交媒体横竖屏）。

剪辑HDR 调色全景声

交付与复盘 PHASE 06

交付全部母版与素材归档，提供十二个月素材保管服务，并组织项目复盘会，把经验沉淀进下一部作品。

母版交付素材归档项目复盘

THE PEOPLE

片尾字幕很长，
但每一个人都重要

精京影业目前有三十七位全职成员，以及一支长期合作的自由创作者网络。以下是几位核心主创，他们决定了我们作品的底色。

陈 京创始人 / 监制

电影学硕士，监制作品十九部，擅长在商业类型与作者表达之间寻找平衡。

林 若导演 / 编剧

代表作《长夜将尽》《十二楼》，关注城市边缘人群的情感与困境。

周 叙摄影指导

电影摄影与纪录影像双线实践者，偏好自然光与长镜头的表达方式。

苏 蝶后期总监 / 调色师

主导四十余部作品的后期流程，擅长以色彩为叙事服务而非炫技。
